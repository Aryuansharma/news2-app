◈ AS-Browser — Smart Hub

AS-Browser is a browser-style web hub that brings everyday digital experiences together in one interface. It combines weather updates, news, stock quotes, music, web search, and online games in a modern, responsive dashboard.

Built using HTML, CSS, and JavaScript, the project explores interactive UI development, API integration workflows, data visualization, and frontend customization.

✨ Features

- 🌦️ Weather: Search for weather information by city or use the location feature.
- 📰 News: Explore news stories across categories, including technology, sports, business, and science.
- 📈 Stocks: Look up stock symbols and display market information with chart visualizations.
- 🎵 Music: Enjoy a Punjabi music playlist embedded from YouTube.
- 🔎 Web Search: Search the web using DuckDuckGo.
- 🎮 Online Games: Access games and entertainment platforms, including 2048, Dino Run, Sudoku, Chess, and Wordle.
- 🌓 Theme Toggle: Switch between light and dark themes.
- ⚙️ Customization Settings: Adjust brightness, font size, and volume controls.
- 📱 Responsive Navigation: Navigate the application through desktop and mobile menus.
- 🎨 Modern UI: Glassmorphism-inspired cards, custom typography, icons, and interactive elements.

🛠️ Technologies Used

- HTML5 — Page structure and semantic markup
- CSS3 — Styling, layouts, responsive design, and visual effects
- JavaScript — Navigation, interactions, and application functionality
- Chart.js — Data visualization for weather and stock charts
- Font Awesome — Interface icons
- Google Fonts — Syne and DM Sans typography
- YouTube Embed — Integrated music playlist

📂 Project Structure

AS-Browser/
├── index.html
├── style.css
└── script.js

- "index.html" — Defines the application's layout, navigation, pages, settings panel, and external library imports.
- "style.css" — Contains the application's styling and responsive design.
- "script.js" — Handles navigation, theme switching, search interactions, weather and stock features, charts, and settings.

🚀 Getting Started

Prerequisites

- A modern web browser
- An internet connection for external libraries and online services
- API keys, if required by the weather, news, or stock data providers used in "script.js"

Installation

1. Clone the repository:
   
   git clone https://github.com/aryuansharma/AS-Browser.git

2. Open the project folder:
   
   cd AS-Browser

3. Open "index.html" in your browser, or use the Live Server extension in Visual Studio Code.

4. Explore the available sections using the navigation menu.

Note: Live weather, news, and stock information depends on the implementation in "script.js" and the availability and configuration of the relevant data services.

🎯 Project Goals

AS-Browser was created to explore how multiple online utilities can be organized into one cohesive web interface. It demonstrates practical frontend development concepts, including:

- DOM manipulation and event handling
- Multi-page-style navigation within a single HTML document
- Responsive layouts and mobile navigation
- Interactive controls and settings panels
- Third-party library integration
- Chart-based data visualization
- Embedded media and external website navigation
